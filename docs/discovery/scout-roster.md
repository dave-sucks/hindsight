# Scout Roster — the durable bench

> **What this is:** the team of X (Twitter) accounts that keep proving credible, organized by
> theme. The Scout Loop's whole premise is that **the durable asset is the people, not the
> names** — names rotate every 5–10 days, but a good scout stays good for months. This file is
> that bench, so you don't rebuild it from scratch every session.
>
> **Who writes it:** `/discovery-prep` *reads* this (to seed Chat 2 / run Play D — "reuse my
> energy scouts on GLP-1"). `/review-discovery` *updates* it — promotes handles whose calls
> played out, mutes the talkers, logs each session's new finds.
>
> **The scoring rule:** a name's signal = (# trusted scouts independently on it) × (their track
> record). **3+ trusted handles on one name = the "triple-sourced" tier — always priority.**
>
> **Freshness:** re-verify Momentum/Catalyst handles often (their edge is recency); Compounder
> handles last months. Stamp `last verified` per handle.

---

## How to maintain (the level-up loop)

Every few weeks, per handle: *"Of the calls @handle made 60–90 days ago, which actually played
out?"* → bump **tier** up (hitter) or down (talker). `/review-discovery` does this against the
dispatched theses' outcomes; the operator can override from taste.

**Tiers:** ⭐ core (proven, lead with them) · ✅ trusted · 🔍 watch (promising, unproven) ·
🔇 muted (kept for the record so we don't re-add them).
