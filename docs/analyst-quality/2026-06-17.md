## Per-analyst findings + recommended tweaks

### 🚨 Momentum Breakout — the priority. Lever: discovery-style FIRST, then config.

**Finding 1 (the big one): it sources well but does not convert.** 16 morning runs since 5/27,
**1 trade, 0 open positions.** Discovery delivered high-composite breakouts — AMKR (composite 9),
MTSI (9), MRVL (8), SMTC (8), LRCX (8), AVGO (8.5), IREN (9). Nearly all are now **RETIRED or
PASSED without ever being entered.** The PASS rationales cluster on **entry timing**: "below both
SMAs, corrective phase, wrong entry," "RSI/extension," "rejected on entry quality." (The
screenshot's MRVL/MTSI/LRCX are RETIRED watchlist theses, **not** open positions.)

> **Diagnosis:** the names arrive *already extended* — "52-week high + analyst-target hikes +
> already +11% on the day" is an exhausted breakout. The agent (correctly) waits for a clean
> entry; the pullback never comes constructively, momentum fades, the thesis retires. ANALYST_LINEUP
> predicted exactly this: *"every momentum signal looks late."* The overhaul's fix (broaden
> universe + raise minConfidence 70→75) addressed *universe breadth*, not *entry lateness* — so
> the choke persists, arguably tighter.

- **Recommended lever #1 (PULL FIRST) — discovery-prompt style.** Hand to discovery: stop sourcing
  *exhausted* breakouts (already at ATH, already +10% on the day, post analyst-upgrade pile-on).
  Source **early-stage** breakouts instead — first close above a multi-week base, **<5% above the
  pivot**, *before* the upgrade cluster. **Layer:** discovery (data input). **Evidence:** every
  high-composite name PASSED on extension/entry-quality. **Expected effect:** entries the agent can
  actually take → first real post-overhaul fills → a payoff sample to measure.
- **Recommended lever #2 (only if #1 doesn't lift fill rate) — config: `minConfidence` 75 → 70.**
  **Layer:** config. **Evidence:** raising it to 75 to compensate for the broader universe stacked
  with the entry-quality gate to produce ~0 fills. **Expected effect:** more entries. **Risk:** for
  a Momentum seat this is *correct* — we want more shots with asymmetric payoff, NOT a higher hit
  rate. **Do not** judge the result on win rate; judge on payoff ratio once ≥8 trades close.
- **One-lever discipline:** pull #1, give it 2 weeks. Don't pull both at once or you can't attribute.

**Calibration reminder:** Momentum's target is **payoff ≥2:1 / positive expectancy**, NOT 70–80% WR.
A 35–45% win rate with 2.5:1 winners is a *success* for this seat. Tuning it toward a high hit rate
would destroy the edge.
