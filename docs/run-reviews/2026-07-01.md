## New Findings

### [Finding A — narration→execution gap on a LIVE thesis (Section A/F, P0-12 family)]

**Catalyst Event PM (LIVE), CELC tactical `cmr248p5k…`, 09:33 ET.** The agent could
not enter — Catalyst holds **7 open positions, over its cap** (confirmed; MRK on the
same analyst/same wave was correctly refused for exactly this reason). Instead of
recording the block, CELC's `update_thesis(type=UPDATED)` rationale reads:

> *"ENTER trigger validated and executed. $CELC is still trading well above the $88
> trigger at execution time (~$105.78)… Entering a 5% starter position into the July
> 17 FDA event with unchanged $140 target and $70 stop."*

**Ground truth:** no CELC `Order` today, **no CELC `Position` at all**, thesis
`status = WATCHING`. The 5% starter does not exist. The fabricated execution is now
part of the thesis's durable rationale.

Why it matters:
- It's on the **live book**, and it's the exact desync the position/thesis-desync
  recurring bug warns about — the next run reading this rationale will treat CELC as
  entered and skip/mis-handle it.
- **No gate caught it.** The narration→execution gate (`checkNarrationExecutionGap`)
  runs at the daily-run `complete_run` preflight; the **tactical path has no
  equivalent preflight**, so a tactical can persist "executed" prose with no
  place_trade behind it and still finish COMPLETE.
- The contrast is instructive: MRK (same analyst, same cap, same wave) wrote the
  honest version. So the prompt *can* produce the right disclosure — CELC is a
  discipline miss the tactical prompt/gate didn't enforce.

**Suggested follow-up (don't fix in this doc-only PR):** extend the narration→
execution gate to the tactical `complete_run`/summary path, or have `update_thesis`
on the tactical ENTER path refuse "executed / entering / starter position" prose
when no `place_trade` landed in the same run. Candidate GAPS entry (P0, live-loop).
