   no RunEvent, no `toolStats` activity, just a 241s wall-clock timeout. Is
   the OpenAI call hanging? Is the agent looping internally without
   emitting? Is it a system-prompt size issue specific to this analyst's
   sectors/tickers config? Same shape as 2026-05-11 silence.
2. **Is the Intraday Momentum Scalper promotion-fail-after-complete a race
   or by design?** Order of events: `run_summary` (12:10:30.298) →
   `run_complete` (12:10:30.534) → `run_failed` Promotion check failed
   (12:10:31.068). Status stayed COMPLETE. Whether this is intended (gate
   warns but doesn't override after completion) or a race condition is
   unclear from the data alone.
3. **Promotion gate keyword list scope.** Today two runs failed because the
   model's rejection rationale didn't include one of the gate's accepted
   keywords (volume/regime/news/R/R/liquidity/etc.). Both rationales were
   reasonable in plain English ("outside our current universe focus on
   Information Technology" for GOOGL; the MU case wasn't deeply read).
   Is the keyword list intentionally narrow, or is "out-of-universe" a
   miss?
4. **Tech Momentum Trader's 4 failed `update_thesis` calls on AMD.** All
   four were rejected by "stopLoss must be below entry for LONG" validation.
   Tool calls counted in toolStats but zero ThesisUpdate rows persisted.
   Is this a known pattern? The agent kept narrating the next attempt with

```sql
-- Morning runs today
SELECT r.id, ac.name AS analyst, ac."useV2Prompt", r.status,
       (r."startedAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York') AS started_et,
       EXTRACT(EPOCH FROM (COALESCE(r."completedAt", NOW()) - r."startedAt"))::int AS elapsed_s,
       r.parameters->>'error' AS error_text
FROM "ResearchRun" r
LEFT JOIN "AgentConfig" ac ON ac.id = r."agentConfigId"
WHERE r.mode = 'MORNING_PLAN'
  AND (r."startedAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York')::date = DATE '2026-05-12'
ORDER BY r."startedAt";

-- Tactical runs today
SELECT r.id, ac.name AS analyst, r.parameters->>'ticker' AS ticker,
       r.parameters->>'predicateKind' AS predicate_kind,
       r.parameters->>'action' AS action, r.status,
       EXTRACT(EPOCH FROM (COALESCE(r."completedAt", NOW()) - r."startedAt"))::int AS elapsed_s,
       r.parameters->>'error' AS error_text
FROM "ResearchRun" r
LEFT JOIN "AgentConfig" ac ON ac.id = r."agentConfigId"
WHERE r.mode = 'INTRADAY_TACTICAL'
  AND (r."startedAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York')::date = DATE '2026-05-12'
ORDER BY r."startedAt";

-- Discovery runs today
SELECT r.id, ac.name AS analyst, r.status
FROM "ResearchRun" r
LEFT JOIN "AgentConfig" ac ON ac.id = r."agentConfigId"
WHERE r.mode = 'DISCOVERY'
  AND (r."startedAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York')::date = DATE '2026-05-12';

-- Per-tool totals across MORNING_PLAN runs today (regex over RunMessage.content)
WITH today_morning_runs AS (
  SELECT r.id FROM "ResearchRun" r
  WHERE r.mode = 'MORNING_PLAN'
    AND (r."startedAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York')::date = DATE '2026-05-12'
),
toolcall_rows AS (
  SELECT (regexp_matches(rm.content, '"type":"tool-call","toolCallId":"[^"]+","toolName":"([^"]+)"', 'g'))[1] AS tool_name
  FROM today_morning_runs tr JOIN "RunMessage" rm ON rm."runId" = tr.id
)
SELECT tool_name, COUNT(*) AS n FROM toolcall_rows GROUP BY tool_name ORDER BY n DESC;

-- Fix #0: NEAR_TARGET / NEAR_STOP rows today
SELECT COUNT(*) FROM "PositionManagementAction"
WHERE ("createdAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York')::date = DATE '2026-05-12'
  AND "actionType" IN ('NEAR_TARGET','NEAR_STOP');

-- Trades + closes today
SELECT symbol, direction, status, quantity, "avgCost", "openedAt",
       "closedAt", "closeReason", "closeSource", "realizedPnl"
FROM "Position"
WHERE ("openedAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York')::date = DATE '2026-05-12'
   OR ("closedAt" AT TIME ZONE 'UTC' AT TIME ZONE 'America/New_York')::date = DATE '2026-05-12'
ORDER BY COALESCE("closedAt", "openedAt");

-- Overdue-review backlog
SELECT
  COUNT(*) FILTER (WHERE status::text IN ('ACTIVE','WATCHING')) AS active_or_watching,
  COUNT(*) FILTER (WHERE status::text IN ('ACTIVE','WATCHING')
                   AND "nextReviewAt" < (NOW() - INTERVAL '7 days')) AS overdue_7d,
  COUNT(*) FILTER (WHERE status::text IN ('ACTIVE','WATCHING')
                   AND "nextReviewAt" < NOW()) AS overdue_any
FROM "Thesis";

-- RunEvent details (to distinguish true failures from quality-gate failures)
SELECT "runId", type, title, LEFT(message, 300) AS msg, "createdAt"
FROM "RunEvent"
WHERE "runId" IN (<today's morning run ids>)
ORDER BY "runId", "createdAt";
```
