## New Findings

### [A/G] P1-18 — `place_trade` rejects a valid trade when the model passes a stray `analyst_id`

The headline finding. Full repro + fix path filed in [`GAPS.md` → P1-18](../GAPS.md).
Summary: `effectiveAnalystId = ctx.analystId ?? args.analyst_id` already prefers
the run-bound analyst, so a hallucinated `args.analyst_id` is *not* used for the
trade — but the ownership check at lines 470-477 still throws on it, killing the
trade. The fix is to only honor/validate `args.analyst_id` when `ctx.analystId`
is unset (i.e., principal-chat). In tactical/daily/morning runs `ctx.analystId`
is always set, so a stray arg should be ignored. **Cost today: one missed HIGH-
conviction LIVE entry (ARQT), silently.** Intermittent (model-hallucination-gated)
but it sits directly in the live trade path.
