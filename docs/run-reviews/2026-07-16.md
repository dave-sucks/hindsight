### [Finding B — Section I item 3/6] Shape gate vs gain-locked floor: MU stop lowered 940→840
`update_thesis` shape gate (LONG: target > entry > stop) rejects a `stopLoss`
at/above cost basis — but a gain-locking floor above cost basis is the entire
point of the ratchet. MU (avgCost ≈$943.67 post-ADD) carried a $940 floor; the
7/14 edit lowered it to $840 explicitly *"to satisfy shape discipline."* The
trigger-ladder protection (trailing rung) remains, so the position isn't naked,
but the `stopLoss` column — which mirrors to Positions and price-monitor — now
understates protection by $100. **The Ratchet Invariant and the shape gate
contradict each other on winners.** Fix options: (a) relax the shape gate for
HOLDING theses (allow stop ≥ entry when gain-locked), or (b) declare trigger
rungs the sole home of gain floors and stop mirroring them into `stopLoss`.
Candidate GAPS entry.

### [Finding C — Section I item 4] 7/13 protective fires tagged MANUAL → wrongly suppressed
All 7/13-morning tactical closes carried `closeReason=MANUAL` (EWTX ×3, VRDN,
XENE, MU); ARQT alone carried `STOP`. Consequence: EWTX's genuine floor breach
(−8.1% day, below the $42 floor) was tombstoned by the P1-28 cooldown — a
protective exit suppressed as if it were a discretionary re-pitch, the exact
mis-route the rubric predicted. From 7/14 every protective close carries `STOP`
(consistent with #490 deploying midday 7/13), and #490's risk-exit carve-out then
works. **Watch item:** one more window of correct STOP tagging before calling it
closed. EWTX itself recovered above its floor and is green (avgCost $40.93), so
no money was lost to the suppression — this time.

### [Finding D — cost/prompt] `complete_run` / `record_run_summary` retry churn
PEAD 7/15: `complete_run` ×8 + `record_run_summary` ×7 in one 87s run. Secular
7/14: ×7 / ×7. The preflight refusals loop (refusal → more work → retry) and each
retry re-generates a summary. Runs do complete, so this is a token tax, not a
correctness bug — but it's new since the Spine added audit obligations. Worth a
look at whether the refusal envelope tells the agent *precisely* which thesis is
unaddressed (vs making it re-derive).

### [Finding E — proposal fatigue, deliberate-hold edition] DELL floor expiries
DELL breached its $428 floor 7/13 and 7/15; both proposals expired unclicked.
Per the non-negotiables an expiry-as-hold is legal, but the rung stays armed and
will re-fire indefinitely, spawning a tactical + proposal + push each time. The
principal's own ARQT/VRDN reject messages show the better pattern (reject with a
re-review level). Missing affordance: a one-click "hold + retune floor to $X" on
the proposal card — see Improvement 5.
