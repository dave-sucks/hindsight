## New Findings

### F1. Narration-gate false-positive on update_thesis-as-cleanup (medium)

Earnings Drift's run did exactly the right thing — closed NVDA before
earnings, manage_position'd AVGO + TSM live positions, AND cleaned up 3
stale-thesis rows whose positions don't exist anymore (AMD, ASML, MU) by
calling `update_thesis(change_status: 'CLOSED')` on them. Run summary
narrated this work as *"close submitted while still profitable"* (NVDA, real
close) and *"adjusted by aligning the live target/stop"* (TSM, real
manage_position) — but ALSO *"AMD closed"* (which means "the AMD zombie
thesis got its status flipped via update_thesis", not "an open AMD position
was closed via close_position").

The narration gate is per-ticker:

> Narration→execution gap: 2 tickers narrated an action with no
> corresponding tool call (AMD narrated close_position ("closed") with no
> tool call; TSM narrated manage_position ("adjusted by aligning the live
> target/stop") with no tool call).

The agent had narrated "closed" near AMD and "adjusted" near TSM, then
searched for close_position(AMD) / manage_position(TSM) tool calls and
didn't find them — even though `update_thesis(ticker=AMD, change_status:
'CLOSED')` happened at 12:02:28 (priceAtTime $424.10).

Two issues stacked:

1. **gpt-5.5 vocabulary** — the model uses "closed" / "adjusted" naturally
   for thesis-state changes. gpt-4o's prose was less natural so the regex
   didn't hit. The new model exposes the gate's false-positive surface.
2. **The gate doesn't recognize update_thesis as a satisfying call.** A
   change_status that maps the thesis to a terminal state (CLOSED /
   INVALIDATED / ARCHIVED) should count as "I closed it" for narration-gate
   purposes when the prose says "closed."

**Fix path** — three-layer principle says this is a **tool/gate problem**,
not a prompt problem:

- (a, narrow) Teach the narration gate that for tickers where update_thesis
  with `change_status` in `(CLOSED, INVALIDATED, ARCHIVED)` was called, the
  prose verbs "closed" / "exited" / "invalidated" / "archived" are
  satisfied — even if close_position / manage_position weren't called.
- (b, broader) Loosen the gate to accept any thesis-state change as
  satisfying any of the action verbs. Risk: lets the agent get away with
  saying "closed" when it didn't actually do anything that fits the prose.
  (a) is safer.

Earnings Drift's underlying work was correct end-to-end. The run shouldn't
have been marked FAILED. The 3 retries on record_run_summary + 3 retries
on complete_run that the agent fired after the gate failed it pushed total
tool calls to 31, which is the cap — explaining the FAILED state.
