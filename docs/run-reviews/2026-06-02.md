### NVDA TIME_ELAPSED runaway (15:45 ET → 16:55 ET)

After NVDA flipped WATCHING → ACTIVE at 12:48 ET, the HELD-side trigger
template stamped a TIME_ELAPSED 14d REVIEW with `cooldownDays: 0`. The
thesis's `createdAt` was 2026-04-27, so the predicate evaluated true the
instant it landed. With 0 cooldown + sticky predicate + 5-min evaluator
cron = infinite loop.

**15 fires, 70 min, 11 COMPLETE + 4 FAILED.** The agent dutifully responded
each time with "the live $NVDA position is only 0 days old, holding" — the
agent self-corrected the *decision* each iteration but the *trigger kept
firing*. Manual intervention came 2 days later when the principal noticed.

The 4 FAILED runs at 16:40–16:55 are OpenAI transient errors (`req_*` IDs
from `help.openai.com`), unrelated to the loop itself — just where the
provider started rate-limiting / failing on the burst.
